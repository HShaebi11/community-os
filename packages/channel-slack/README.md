# @community-os/channel-slack

Slack channel adapters for Community OS — `slackChannel()` Socket Mode listener (outbound WS, works behind NAT) + `slackEvents()` Events API webhook receiver for production.

Part of [Community OS](https://github.com/HShaebi11/community-os) — MIT.
Docs: [`docs/CHANNELS.md`](https://github.com/HShaebi11/community-os/blob/main/docs/CHANNELS.md)
