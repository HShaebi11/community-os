# @community-os/channel-discord

Discord channel adapter for Community OS — raw Gateway WebSocket listener (no discord.js). Requires a bot token + the privileged MESSAGE_CONTENT intent.

Part of [Community OS](https://github.com/HShaebi11/community-os) — MIT.
Docs: [`docs/CHANNELS.md`](https://github.com/HShaebi11/community-os/blob/main/docs/CHANNELS.md)
