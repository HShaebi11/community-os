# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) v2.1.

Be kind, be direct, assume good intent. No harassment, no personal attacks, no
publishing anyone's private information — which matters doubly here, because
this software processes real communities' chat exports. Never paste someone's
chat data, email, or identifiers into an issue or PR.

Instances of unacceptable behavior can be reported to the maintainers through
the repository's issue tracker or the contact in `SECURITY.md`. Maintainers
will review and act proportionately, up to removal from the project.
